# Extraction Engine Validator

### Описание проекта
Система автоматизированного сбора и валидации данных о товарах с использованием микросервисного подхода. Проект состоит из асинхронного экстрактора (клиент) и сервера валидации (API).

**Ключевой функционал:**
*   **Асинхронный сбор данных:** Клиент на базе `aiohttp` и `BeautifulSoup4` параллельно обрабатывает страницы сайта-донора.
*   **Двухуровневая валидация:** Сервер на `FastAPI` проверяет входящий JSON с помощью `Pydantic`.
*   **Безопасность данных:** Строгий контроль схем через `ConfigDict(extra="forbid")`, исключающий передачу лишних или вредоносных полей.
*   **Автодокументация:** Интерактивная песочница Swagger UI для тестирования эндпоинтов.

---

### Технологический стек
*   **Язык:** Python 3.10+
*   **Framework:** FastAPI
*   **Validation:** Pydantic v2
*   **Async Network:** aiohttp, asyncio
*   **Parsing:** BeautifulSoup4
*   **Server:** Uvicorn

---

### Структура проекта
*   `main.py` — Серверная часть. Описание схем данных, правил валидации и эндпоинтов.
*   `client.py` — Клиентская часть. Асинхронный парсер с логикой отправки данных на сервер.

**Запуск сервера**
python -m uvicorn main:app --reload

После запуска документация доступна по адресу: `http://127.0.0`

**Запуск парсера (в новом окне терминала)**
python client.py

---

### Валидация данных
Сервер контролирует следующие параметры:
*   **product_id**: Артикул (строка от 5 до 12 символов).
*   **price**: Цена (float, строго в диапазоне 10.0 — 1,000,000.0).
*   **proxy_session**: Кастомный валидатор на наличие обязательного префикса `PROXY_SUB_`.
